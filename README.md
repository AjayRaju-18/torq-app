# TORQ - Mechanical Engineering Assistant

A specialized mechanical engineering chatbot powered by GROQ's LLM with RAG (Retrieval Augmented Generation).

## Features
- 📄 Upload mechanical engineering PDFs
- 🤖 Chat with AI trained on your documents
- 🔄 Toggle between RAG and normal chat mode
- 💬 Conversation memory

## Usage
1. Upload mechanical engineering PDFs
2. Enable RAG mode to use uploaded documents
3. Ask questions about mechanical engineering
4. TORQ will provide detailed answers with sources

## Environment Variables
Set `GROQ_API_KEY` in Hugging Face Spaces settings.
